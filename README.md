# GenAI Value Safety Incident Repository

This repository provides a structured case repository of value safety incidents related to Generative Artificial Intelligence (GenAI).

The repository is constructed based on a lifecycle-oriented risk taxonomy of GenAI value safety. It contains 1,126 real-world incidents collected from multiple public sources, including news reports, AI incident databases, regulatory documents, academic literature, industry reports, and NGO publications.

## Purpose

This case repository is built to support research on GenAI value safety. It provides empirical materials for:

- Identifying and classifying GenAI value safety risks
- Analyzing how value safety risks emerge across different stages of the GenAI lifecycle
- Enabling further comparative and trend analysis by other researchers

## Scope

The repository focuses on incidents directly related to generative AI systems, including:

- Large language models
- Text generation models
- Image generation models
- Video generation models
- Audio generation models
- Multimodal generative models

The repository excludes cases that only involve traditional discriminative, predictive, or recommendation-based AI systems without generative capabilities.

## Data Fields

Each incident is organized with structured metadata, which may include:

- Incident ID
- Incident title
- Incident description
- Country or region
- Date
- Lifecycle stage
- Risk type
- Source
